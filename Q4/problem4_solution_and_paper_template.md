## 二、先用通俗的话理解 Q4

把大模型想成一辆车：

1. Q1 评价“燃料好不好、怎么混合”，即数据质量和配比。
2. Q2 研究“发动机大小、燃料数量和质量如何影响表现”，得到 Loss 公式。
3. Q3 研究“钱有限，发动机、油量、油品怎么买最划算”，得到资源配置。
4. Q4 用真实车型成绩检查历史进步，再问：“以后投入涨得慢一些，成绩还能涨多少？”

这里最难的是两座桥：第一，Loss 不是考试分数，需要用同时有 Loss 和成绩的模型建立映射；第二，成绩改善不全是规模变大，需控制规模后估计剩余时间趋势。剩下的变化可能来自新技术，也可能来自未记录的数据差异，不能统称为已经证明的技术因果贡献。

本方案没有改掉前三问；它把前三问的输出用于历史解释和条件预测。

## 三、在 Mac 上运行

### 3.1 推荐：使用完整 ZIP

下载并解压 `Q4完整交付包.zip`，保留 `Q4` 文件夹的内部结构。不要只把 Python 文件单独移走，因为它会调用 Q3 源代码并读取 Q2 接口。

打开 Mac 的“终端”，输入 `cd ` 后把解压得到的 **Q4 文件夹**拖进去，再回车。随后运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas scipy matplotlib
python problem4_solution.py \
  --data-root "/Users/youyu/数模建模方法/中文题目/F题/real_attachments/C_efficiency_evolution" \
  --bootstrap 200
```

终端命令不要粘进 IDLE 的 `>>>` 后面。使用 `python -m pip` 可以把包安装到当前运行脚本的解释器环境，避免先前“装了包但 IDLE 仍找不到”的情况。

代码使用 Python 3.10 及以上语法；本次已在这台 Mac 的 Python 3.12.14 环境完成运行，实际依赖版本记录于 `runtime_versions.json`。其他版本的安装兼容性以相应依赖包是否提供支持为准，不承诺所有版本都已测试。

默认结果写入脚本目录下 `problem4_outputs/时间戳/`，每次新建目录。指定 `--output-dir` 时必须给一个不存在的目录，防止覆盖旧结果。

**正确结论：当前可比域内桥接略优于均值，但跨族桥接和时间预测未稳定优于基线，尚不能宣称高精度。** 0.3335 分的小误差不能推广成整个 Q4 的预测误差，更不能换算成“准确率 99%”。

### 5.2 条件贡献分解

| 分量 | 点估计，分 | 条件 Bootstrap 95% 区间，分 |
|---|---:|---:|
| 规模项 | 0.3380 | [−0.1420, 0.6848] |
| 非规模时间项 | 3.4048 | [0.1869, 9.8189] |

点估计占比为 9.03% 与 90.97%。规模占比区间为 [−2.80%, 36.83%]，非规模时间项为 [63.17%, 102.80%]；199/200 次重采样总变化为正，占比区间按这些有定义的抽样计算。

区间超出 0–100% 不是格式错误：两个贡献可能方向相反。不要人为截断成看起来漂亮的百分比，也不要把非规模项进一步拆成“架构占多少、对齐占多少”，数据不支持这种细分。

### 5.3 示例预测

| 类型 | 当前锚点 | 12 个月 | 条件区间 | 24 个月 | 条件区间 |
|---|---:|---:|---|---:|---|
| 预训练/持续预训练 | 27.65 | 29.62 | [17.11, 38.30] | 31.67 | [18.14, 42.96] |

135 组资源配置均出现 $Q^*=1$，这表示在题定成本、当前预算和迁移参数下最优解达到质量上界，不能推广成现实中总应该把数据质量做到完美。所有未来配置都超出 Q2 的 B1 拟合范围，预测 Loss 也低于 High 桥接的观测范围，因此长期预测应突出外推风险。

## 六、论文正文写作模板

下列段落以本次实际运行为基础，可修改后使用。附表和图片路径见第四节；若换数据、代码或参数，需要重新填数。

### 6.1 问题分析与整体路线

> 第四问要求在历史模型表现中区分规模扩张与非规模变化，并在算力增长放缓条件下预测能力前沿。前三问建立的数据质量、配比与资源配置机制最终输出验证损失，而第四问使用的是下游任务分数，因此首先构建 Loss–Benchmark 桥接。在此基础上，以参考质量和配比下的标度律刻画规模项，利用模型族与类型控制后的时间趋势表示非规模变化，再通过两因素 Shapley 分解消除贡献计算的顺序依赖。最后，将外生算力路径输入第三问求解器，以近期能力前沿为锚点完成 12/24 个月情景预测。

建议此处插入四问接口图：`Q1 质量/配比 → Q2 广义 Loss → Q3 预算最优配置 → Q4 能力映射与前沿`；C1/C3/C4/C6/C8 从侧面进入 Q4。

### 6.2 数据口径与预处理

> 综合能力定义为六项榜单任务分数的等权平均，预训练类与聊天微调类分开报告。经开放权重/许可、类型、分数完整性和参数有效性筛选，4,576 条榜单记录中保留 1,329 个模型。与 C4 连接后，52 个模型具备完整且可用于密集模型公式的参数量、数据量和训练算力。C3 与 C1 存在大量重叠，历史来源分数又存在评分口径差异，故用于来源内趋势和口径敏感性，未直接并入主回归。C8 的实际子任务明细产生 44,616 条 BBH 记录，用于验证任务聚合和排序一致性。

随后给出开放筛选规则、C4 连接审计和时间基准，特别说明发布日期与提交时间的区别。

### 6.3 模型建立

按以下顺序插入公式文件中的公式，避免只罗列算法名称：

1. 综合分和 logit 变换；解释有界分数为什么不宜无限线性外推。
2. Q2 标度律及历史参考 Loss；说明固定 $Q_0,\mathbf p_0$ 的原因。
3. 带单调约束的六任务桥接；给出 High/Medium 分层及参考族。
4. 规模残差的时间动力学；说明族权重、类型控制和正则化。
5. 条件 Shapley 分解；给出两因素贡献之和的恒等式。
6. 外生预算路径、Q3 原约束、前沿锚点和预测公式。
7. 验证拆分、Bootstrap 层次及未覆盖的不确定性。

可用解释：

> “外生给定”表示算力增速、上下文长度、质量成本机制由情景先行指定，模型回答各情景下应该怎样配置资源以及对应表现，不把这些条件本身当作已经由数据估计出的事实。

### 6.4 模型检验

> 高可比 Pythia 桥接的留一 MAE 为 0.3335 分，略低于均值基线的 0.3756 分。然而跨族敏感性桥接 MAE 为 10.8775 分，三个时间留出误差也未稳定优于均值基线。上述结果说明，目前样本足以支持可比域内的映射演示，但对跨族迁移和长期外推的证据较弱。因此本文将预测作为结构化情景结果，未据此声称已获得高精度长期预测器。

这里应插验证表，不能只展示拟合曲线或训练误差。时间留出采用固定桥接，不是严格的全流程时间交叉验证；需在表注说明。

### 6.5 贡献与预测结果

> 在固定模型族和类型组成的条件下，早晚组模型反事实变化为 3.7429 分，其中参考规模项为 0.3380 分、非规模时间项为 3.4048 分。点估计贡献占比为 9.03% 和 90.97%，但重采样显示比例不确定性较大，规模贡献甚至可能为负。因此该结果仅表示在当前标度映射与样本选择下，时间残差对模型解释的贡献较大，并不能识别具体技术类别的因果效应。

预测结果插入第五节的示例表，并把完整 540 情景作为附件。表下注明：截止日期、许可口径、评分构成、成本函数、上下文、年增长率、趋势保持率和条件区间定义。

### 6.6 优点、局限与改进

> 本方案的优势在于四问接口一致，资源约束与能力映射相分离，且保留了原始数据可比性、外推与重采样审计。主要不足是 High 桥接仅 7 个模型，完整历史匹配样本仅 52 个，缺乏逐模型质量及配比观测，历史训练成本与总预算之间也存在口径假设。未来需要扩充同一验证集、同一 tokenizer、相同任务版本下的桥接记录，并补充可靠的模型发布日期与后训练成本，才能进一步改善跨族预测和技术归因。

可以进一步比较单调样条、分层贝叶斯或低维多能力模型，但应采用相同族留出/时间留出及均值基线。当前不因为算法更复杂就预设其一定更准。
