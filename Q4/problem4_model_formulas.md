# 问题四模型公式与推导

本文件对应 `problem4_solution.py`。方案为：**分层 Loss–Benchmark 桥接 + 带模型族控制的时间动力学 + 条件 Shapley 分解 + 调用 Q3 的算力情景预测**。它承接原 Q1–Q3 的实际接口，不重新定义质量分数，也不重新拟合前三问。

主结果是给定模型与迁移假设下的条件估计。现有观察数据不能分别识别架构、对齐、数据工程各自的因果贡献；本模型把控制参考规模效应后的时间变化合称为“非规模时间项”。

## 1. 四问如何衔接

| 问题 | 已确定的方法或接口 | 在 Q4 中的用途 |
|---|---|---|
| Q1 | 质量评分、领域质量映射、二次 ILR 岭回归的配比响应 | 通过 Q2 导出的参考配比和质量锚点进入，不重读 A |
| Q2 | 规模双幂律、质量响应、相对配比响应组成广义标度律 | 提供参数、参考质量和 200 组参数 Bootstrap |
| Q3 | 固定参考配比，解析消去数据量，网格搜索后 SLSQP 优化 | 在未来各预算下重新求解最优配置与 Loss |
| Q4 | Loss 转为能力分数，分解历史变化，预测未来条件前沿 | 使用 C 类数据检验和校准 |

Q4 主情景固定 $\mathbf p=\mathbf p_0$，不是再次优化 17 维配比。调用 Q3 原代码的 `load_model`、`load_context_lengths`、`optimize_scenario` 和 `generalized_loss`。

## 2. 样本、单位与可比性

### 2.1 数据使用

| 数据 | 实际使用方式 | 不能做的推断 |
|---|---|---|
| C1 | 开放模型筛选；六任务综合分；最近三个月前沿锚点 | 提交时间不等于发布日期 |
| C3 | 来源—年份汇总；识别与 C1 重复；来源内趋势敏感性 | 不将旧文献分数、缺失记零与新榜单直接混合回归 |
| C4 | 匹配参数量、训练 tokens、FLOPs、开放权重和发布日期；设预算情景 | 不用缺失的训练数据量冒充实测，也不把预训练算力当完整生命周期算力 |
| C6 | 按 High/Medium 可比性分层建立 Loss–Benchmark 桥接 | C6 包含 C5，不重复叠加；不同语料或 tokenizer 的 Loss 不自动可比 |
| C7 | 提供 Q3 的五种上下文长度 | 上下文长度为外生情景，不是优化变量 |
| C8 | 逐 JSON 提取 BBH 叶子子任务，计算宏平均和样本数加权平均 | 原始正确率与榜单变换分数不直接作差 |

开放口径为“C1 中可识别的公开许可，或 C4 明示开放权重”；C4 明示不开放时排除。许可白名单详见代码 `LICENSES`，许可与权重信息均未核实的自定义许可记录排除。这是可复现的开放权重/许可代理口径，不等于逐条完成许可证法律审查，也不代表严格 OSI 定义。

基础预训练与持续预训练归入 `pretrained`；聊天和微调归入 `chat_finetuned`。合并模型、多模态及其他类型不纳入主比较。类型是控制变量，前沿预测也分类型报告。

C1–C4 通过规范化模型名连接，输出所有匹配行与重复键供核对；同键选字段最完整的 C4 记录，同一模型的镜像选最早提交。检查参数量是否在 25% 容差内；具有 MoE 或激活参数歧义的记录不代入密集模型公式。名称连接仍可能错配，不能替代正式的人工模型版本核验。

历史规模分解要求 $N,D,C$ 均实际可得；不以 $D=C/(6N)$ 补齐。主样本采用 C4 的**模型发布日期**作为时间轴；榜单锚点采用 C1 的**提交时间**。这是“用共同基准回顾评价不同发布日期模型”的分析，不是逐日保存下来的真实历史排行榜。

### 2.2 综合能力分数

六个任务为 IFEval、BBH、MATH Lvl 5、GPQA、MUSR、MMLU-PRO，各按附件中的 0–100 分口径：

$$S_i=\frac16\sum_{k=1}^{6}s_{ik}.$$

等权宏平均避免任意人为偏好。实测与 C1 的 `Average ⬆️` 差异仅为浮点误差。该分数衡量六项任务的平均表现，不代表全部智能能力。

定义稳定变换

$$z(S)=\operatorname{logit}\!\left[\operatorname{clip}(S/100,0.001,0.999)\right],\qquad \sigma(x)=\frac1{1+e^{-x}}.$$

对 C8 的 BBH 子任务集合 $\mathcal K_i$，使用 `acc_norm,none`：

$$B_i^{macro}=\frac{100}{|\mathcal K_i|}\sum_{k\in\mathcal K_i}a_{ik},\qquad
B_i^{micro}=100\frac{\sum_k n_{ik}a_{ik}}{\sum_k n_{ik}}.$$

$n_{ik}$ 优先取 `effective`，再取 `original`，均不可得时取 1 并保留原始记录。排除 BBH 总分父节点，防止重复计数。C8 与 C1 只比较覆盖和 Spearman 排序一致性，不把不同评分变换造成的数值差当模型误差。

## 3. 继承 Q2 的广义标度律

令 $n=N/10^9$、$d=D/10^{11}$，则

$$L=E+\left(An^{-\alpha}+Bd^{-\beta}\right)
\exp\{\gamma\kappa[\bar Q(\mathbf p)-Q]+\lambda r(\mathbf p)\}.$$

本次重跑 Q1、Q2 得到

$$E=1.6894822654,\ A=0.3540643386,\ B=0.3420160241,$$
$$\alpha=0.3399210767,\ \beta=0.2797959769,\ \gamma=0.4101602835,\ Q_0=0.6109136649.$$

使用 $\kappa=\lambda=1$ 的原主情景。$Q_0$ 是 Q1 体系下的参考归一化锚点，不是历史每个模型实测的训练数据质量。

由于 C4 通常没有历史 $Q_i,\mathbf p_i$，历史规模项一律用参考条件：

$$L_i^{ref}=E+A(N_i/10^9)^{-\alpha}+B(D_i/10^{11})^{-\beta}.$$

这样，历史数据质量和配比的未观测差异被留在残差中。不能声称已经逐模型测量并控制了它们。

## 4. Loss 到能力的桥接

### 4.1 主桥接：只使用高可比记录

对任务 $k$ 拟合

$$z(s_{ik})=a_k-b_k L_i+c_k I_i^{chat}+\sum_{f\ne f_0}u_{kf}I_{if}+e_{ik},\qquad b_k\ge0.$$

High 主模型只含 7 个 Pythia 模型，没有模型族哑变量；聊天指示全部为零，因此其系数由惩罚压到零，不能解释为识别了聊天效应。主约束表示在同一参考口径下 Loss 越低，能力不下降。

用带约束的岭最小二乘求解：

$$\min_{\theta_k:b_k\ge0}\sum_i w_i[z(s_{ik})-X_i\theta_k]^2+
0.2\sum_{j\ne\mathrm{intercept}}\theta_{kj}^2.$$

代码直接在当前量纲上拟合，未做特征标准化。0.2 是预先固定的正则化设置，未宣称是全局最优超参数。

参考模型的综合映射为

$$H(L)=\frac{100}{6}\sum_{k=1}^6\sigma(a_k-b_kL),\qquad G(L)=z(H(L)).$$

### 4.2 中等可比样本只作敏感性

High+Medium 模型增加族截距及聊天指标，权重分别为 1 和 0.25，以 Pythia 为参考族。族截距可以吸收部分来源差异，**不能保证修复未知的验证语料与 tokenizer 差异**。主桥接按模型留一，敏感性桥接按模型族留一。未见过的模型族按参考截距预测，因此该检验直接暴露跨族迁移的不稳定性。

把 Q2 参考 Loss 与 C6 High Loss 接在一起仍依赖 Pythia 参考评估尺度的可迁移假设；应核对训练检查点、数据清洗和验证集定义。即使都叫 Pythia，也不应认定绝对 Loss 天然完全一致。

## 5. 非规模时间动力学

将能力中参考规模项扣除：

$$r_i=z(S_i)-G(L_i^{ref}).$$

以截止时点 $t_0$ 为原点，$t_i=(\text{发布日期}_i-t_0)/365.25$，单位为年：

$$r_i=a+\tau t_i+\delta I_i^{chat}+\sum_{f\ne f_0}v_f I_{if}+\varepsilon_i.$$

仍采用岭系数 0.2，截距不惩罚；每条记录权重与其模型族记录数成反比，再归一化至均值为 1。这样一个族有很多派生模型时，不会仅因数量多而支配估计。族名称按代码中的模型名规则划分，是可审计但有误差的代理。

该式相当于简单动力学 $dr/dt=\tau$。$\tau$ 不强制为正，可以反映停滞或下降。它包含非规模技术、未测质量、评测污染、样本选择等共同影响；没有干预、工具变量或自然实验，不能把它单独叫作技术进步的因果效应。

## 6. 条件 Shapley 贡献分解

按主样本发布日期的下、上四分位形成早期组和后期组。分别取组内平均参考 Loss $\ell_0,\ell_1$ 和平均时点 $t_0^*,t_1^*$。固定完整样本的族/类型组成：

$$F(\ell,t)=\frac{\sum_i w_i100\sigma\{G(\ell)+a+\tau t+\delta I_i^{chat}+v_{f(i)}\}}{\sum_i w_i}.$$

规模贡献：

$$\Delta_{scale}=\frac12\{F(\ell_1,t_0^*)-F(\ell_0,t_0^*)
+F(\ell_1,t_1^*)-F(\ell_0,t_1^*)\}.$$

非规模时间贡献：

$$\Delta_{time}=\frac12\{F(\ell_0,t_1^*)-F(\ell_0,t_0^*)
+F(\ell_1,t_1^*)-F(\ell_1,t_0^*)\}.$$

因此两者之和严格等于 $F(\ell_1,t_1^*)-F(\ell_0,t_0^*)$。它对两种改变顺序取平均，避免人为规定“先规模还是先技术”造成不同答案。

仅在总变化大于 $10^{-6}$ 时报告占比。若两因素方向相反，占比可以为负或超过 100%，不截断；若总变化非正则不报告“增长贡献率”。这不是原始早晚榜单均值差的精确分解，而是固定族/类型组成后的模型反事实差。

## 7. Q3 优化怎样进入未来预测

### 7.1 外生预算路径

截止日前一年 C4 开放语言模型训练 FLOPs 的 95% 分位数作为 $C_0$。本次为 $7.85865\times10^{24}$ FLOPs。预测情景：

$$C(h;g)=C_0(1+g)^{h/12},\quad g\in\{0,0.10,0.25\},\ h\in\{0,12,24\}.$$

$g$ 是外生设定，意思是“先给定增长率，再推算能力”，不是让优化器自己选择增长率。为核对“放缓”，代码还对过去三年 C4 季度算力 95% 分位数拟合对数线性趋势（每季度至少 3 条）。得到的历史增速只是样本内描述，受披露和样本构成影响，不是行业真实算力增长的精确测量。

历史参考来自预训练 FLOPs，Q3 预算则包含其规定的三类成本。将二者作为同数量级预算来比较是情景假设；未知后训练和部署算力未计入。

### 7.2 完整继承 Q3 成本与约束

$$\min_{N,D,Q}L(N,D,Q,\mathbf p_0),$$
$$6ND+D[g_c(Q)-g_c(Q_0)]_++\eta NDL_{ctx}\le C,\quad\eta=2\times10^{-4},$$
$$Q_0\le Q\le1,\quad N_{min}\le N\le N_{max},\quad D_{min}\le D\le D_{max}.$$

分别使用三种原成本函数：

$$g_{exp}(Q)=10^7e^{6Q},\quad g_{pow}(Q)=5\times10^9Q^4,\quad g_{log}(Q)=2\times10^9\ln(1+10Q).$$

对五个 $L_{ctx}\in\{2048,4096,8192,32768,131072\}$ 分别求解。解析消去

$$D=\frac{C}{(6+\eta L_{ctx})N+[g_c(Q)-g_c(Q_0)]_+}.$$

数值过程为原 Q3 的粗网格搜索加 SLSQP 局部细化，输出 $L^*(C)$、资源配置、预算份额与外推标志；不宣称证明了全局最优。

### 7.3 能力前沿预测

将截止日前三个月、每种模型类型的综合分 95% 分位定义为操作性前沿 $F_{b,0}$。它比单个最大值稳健，但**不是理论最高能力**。

$$\widehat F_b(h)=100\sigma\left[z(F_{b,0})+
G(L^*(C(h)))-G(L^*(C_0))+\rho\widehat\tau h/12\right],$$

其中 $\rho\in\{0,0.5,1\}$，分别表示非规模趋势停止、保留一半、完全延续。未来只叠加相对 Loss 收益，并用当前榜单分数锚定水平，避免直接把 Pythia 的低分截距当所有前沿模型的绝对分数。

Q3 同时优化 $N,D,Q$，所以公式中的优化项是**预算变化后资源配置所带来的收益**，不应全部重新解释成纯参数扩容收益。历史贡献分解则固定质量与配比；两个口径不同。时间项与未来质量投资可能存在重叠，$\rho$ 情景用于暴露该假设，但没有从数据中唯一消除这种重叠。

共有 $3\times5\times3\times2\times2\times3=540$ 条预测情景。不可从中挑最好的一行而隐藏其他结果。

## 8. 验证、不确定性与可识别边界

1. **桥接检验**：High 按模型留一；High+Medium 按族留一；都与训练集均值预测比较。
2. **时间检验**：按主样本发布日期 60%、75%、85% 分位截断，前段拟合动力学、后段评估 MAE/RMSE。桥接固定由 C6 拟合，因此这不是严格的全流程历史信息回放。时间检验不能代替真实 24 个月预测检验。
3. **Bootstrap**：200 次。High 桥接重采样模型；动力学重采样完整模型族；前沿锚点按各类型模型族重采样；抽取 Q2 的一组参数重新计算历史 Loss 和 Q3 配置的 Loss。
4. **优化传播范围**：每次只在已求出的 Q3 配置上重算 Loss，没有每次重新选最优配置；不覆盖 $Q_0$、质量迁移机制、模型形式、预算代理误差及未来新技术冲击。
5. **区间解释**：2.5%–97.5% 分位是上述条件下的 Bootstrap 区间，不是经校准的未来真实分数 95% 预测区间。成本、上下文、增长率、趋势保持率另列为情景，不混成所谓概率区间。
6. **外推审计**：主样本 52 个中 42 个超出 Q2 的 B1 支持范围；本次 135 个 Q3 配置均超出 B1，540 个能力预测的 Loss 也均超出 High 桥接范围。必须在结论中保留这一边界。

## 9. 本次计算的真实结果与含义

- C1 共 4,576 条，按本口径纳入 1,329 个模型；主历史匹配样本 52 个。
- C8 聚合 1,859 个模型、44,616 条 BBH 子任务记录；4 次坏 JSON 读取被记录。与筛选后 C1 匹配 574 个模型，排序相关约 0.9973。
- High 桥接留一 MAE 为 0.3335 分，均值基线 0.3756 分；这一小误差只适用于 7 个低分 Pythia 样本。
- 跨族敏感性桥接 MAE 为 10.8775 分，均值基线 10.3411 分，**没有超过简单基线**。
- 主动力学三个时间留出 MAE 为 11.1606、12.6152、14.3541 分，未稳定优于均值基线。
- 条件 Shapley 点估计：规模 0.3380 分、非规模时间项 3.4048 分，占比 9.03% 与 90.97%。200 次重采样的规模占比区间为约 −2.80% 至 36.83%；这是条件且不稳定的归因，不能写成“技术因果贡献确定为 90.97%”。
- 非规模年 logit 趋势为 0.19125。历史算力季度趋势隐含年增长约 254.31%，三种未来预算情景均比该描述性趋势低。

现阶段应将本方案作为**贯通四问、可复现且诚实报告证据不足的初版**。提高预测可信度需要同一评测集上的更多跨规模桥接、匹配明确的训练数据量和真实纵向记录；增加算法复杂度不能替代这些信息。
