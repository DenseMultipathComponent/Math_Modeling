    **1.广义标度律**
    L(N,D,Q,**p**)，退化成经典形式L(N,D) （质量和配比均满足参考条件：A4）
    参数估计：
    ```
    B1(8次训练)：质量和配比满足参考条件，退化为经典形式，估计规模参数

    ```
    **2.边际效用与弹性**
    ```
    Loss对N,D,Q
    ```
    **3.提升数据质量(Q)与扩大模型规模(N)可相互替代的条件**
    ```
    Loss(Q↑) = Loss(N↑)
    Loss(Q,N) = Loss(Q↑,N↓)
    ```
    **4.不同领域数据之间的替代或互补关系**
    ```
    **p**,互补或替代
    ```

3. #Q3 ***算力约束下的多维资源联合优化与结构性转移***
问题三在算力预算下求解最优配置：**优化，定义**

    **1.优化模型（N,D,**p**,Q）**
    **L_ctx(C7，5类)，C(`10^19`、`10^22`、`10^24`，并选择其他档位)**
    算力消耗：
    *基础训练开销*：6ND，
    *数据质量提升开销*：D[g(Q)−g(Q_0)]+ (**成本函数**g(Q)：指数型、幂函数型、对数渐进型，Q∈[Q_0,1])，
    *长文本注意力开销*：ηNDL_ctx
    ```
    **p**参考配比 ————> 使用全部预算（消去D） ————> 目标Loss，准则C，优化N,Q ————> 粗网格搜索，SLSQP细化 ————> 拉格朗日函数（内点最优）
    ```
    **2.结构性转移**
    任一事件：
    ```
    Q活跃状态改变
    经验配方改变
    资源份额总变差超过 0.10
    以及相邻预算区间的 N,D 弹性变化超过 0.35
    ```
    **3.长文本临界值，敏感度分析**
    ```
    L_ctx=6/η
    可行取值上比较：长文本注意力开销，基础训练开销
    ```
    *经验配比 **p** 影响*
